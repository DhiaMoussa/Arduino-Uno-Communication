
# Arduino Uno Communication System

## Présentation du projet

Développement d'un système de communication entre
cartes Arduino Uno permettant de transmettre et de
recevoir des données dans un environnement embarqué.

L'objectif est d'étudier les échanges d'informations
entre microcontrôleurs.

## Objectifs

- Établir une communication entre cartes Arduino.
- Transmettre des données issues de capteurs.
- Échanger des commandes de contrôle.
- Tester le fonctionnement des échanges.

## Réalisations techniques

- Configuration des cartes Arduino Uno.
- Programmation des fonctions de communication.
- Transmission de données.
- Réception et traitement des informations.
- Échange de commandes entre microcontrôleurs.
- Tests des communications série.

## Technologies utilisées

- Arduino Uno
- Programmation embarquée
- Communication série
- Microcontrôleurs
- Interfaçage de capteurs

## Compétences développées

- Systèmes embarqués
- Programmation de microcontrôleurs
- Communication entre équipements
- Acquisition et transmission de données
- Tests de systèmes électroniques

## Applications

- Systèmes embarqués communicants
- Échange de données entre microcontrôleurs
- Automatisation
